САЙТ ФОТОГРАФА — ИНСТРУКЦИЯ

1. Откройте index.html в браузере, чтобы посмотреть сайт.
2. Загружайте на хостинг всю папку fotograf_site целиком.
3. Не перемещайте index.html отдельно от папки images.
4. Чтобы изменить текст, откройте index.html в редакторе.
5. Чтобы заменить фотографии, положите новые файлы в images и поменяйте имена файлов в index.html.
6. В блоке контактов замените your-email@example.com на свою почту.
7. В блоке «Обо мне» добавьте своё имя и реальную информацию о себе.

Файлы:
- index.html — структура и тексты сайта
- style.css — оформление и адаптация под телефон
- script.js — мобильное меню и просмотр фотографий
- images/ — ваши фотографии, подготовленные для сайта

Сайт сделан на HTML, CSS и JavaScript без сборки и установки библиотек.
